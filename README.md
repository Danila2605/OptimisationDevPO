# СтройМаркет — сайт компании по продаже строительных материалов

Репозиторий командного проекта по дисциплине «Методы оптимизации в разработке программных решений».

## О продукте

Сайт компании по продаже строительных материалов: каталог товаров, карточки материалов, оформление заявки/заказа, информация о доставке и самовывозе.
